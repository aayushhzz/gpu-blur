# Architecture & Kernel Design

This document details the memory layout, kernel implementations, and verification methodology in `gpu-blur`.

## Image Representation

`gpu_blur::Image` ([include/blur_cpu.hpp](../include/blur_cpu.hpp)) stores pixels as a contiguous `std::vector<float>` in row-major interleaved order:

```text
index(x, y, c) = (y * width + x) * channels + c
```

- `channels` is `1` (grayscale) or `3` (RGB).
- Pixel values are floating-point in `[0, 255]`.
- Boundary handling uses **clamp-to-edge** (`clamp_coord` on CPU, `d_clamp` on GPU), mapping out-of-bounds coordinates `< 0` to `0` and `>= limit` to `limit - 1`.

## CUDA Kernel Implementations

All CUDA kernels in [src/blur_cuda.cu](../src/blur_cuda.cu) launch with `dim3 block(16, 16)` (`TILE_W = 16`, `TILE_H = 16`) and `grid((width + 15) / 16, (height + 15) / 16)`. Maximum supported radius is `MAX_RADIUS = 32` (`MAX_KERNEL_SIZE = 65`).

### 1. Naive 2D Box Blur (`boxBlurNaiveKernel`)

- **Memory path:** Reads every pixel in the `(2r + 1) × (2r + 1)` window directly from global memory (`src`).
- **Complexity:** `O((2r + 1)^2)` global memory reads per pixel per channel.
- **Role:** Correctness and performance baseline for comparing against the tiled implementation.

### 2. Shared-Memory Tiled 2D Box Blur (`boxBlurTiledKernel`)

- **Memory path:** Allocates dynamic `__shared__` memory of size:
  ```cpp
  (TILE_W + 2 * radius) * (TILE_H + 2 * radius) * sizeof(float)
  ```
- **Cooperative load:** Processes one channel at a time. Threads stride across `(tile_rows × tile_pitch)` to load both the `16 × 16` interior and the `r`-pixel halo with clamp-to-edge coordinates, followed by `__syncthreads()`.
- **Stencil compute:** Each in-bounds thread accumulates its `(2r + 1) × (2r + 1)` window from fast on-chip shared memory, then synchronizes before the next channel reuses the buffer.

### 3. Separable Gaussian Blur (`gaussianBlurHorizontalKernel` + `gaussianBlurVerticalKernel`)

- **Constant memory:** The normalized 1D Gaussian kernel generated by `make_gaussian_kernel_1d(radius, sigma)` is copied once to `__constant__ float d_gauss_kernel[65]` via `cudaMemcpyToSymbol`, taking advantage of constant-cache broadcast across warps.
- **Two-pass factorization:**
  1. **Horizontal pass:** Convolves `src` along `x` into intermediate buffer `d_tmp` (`2r + 1` taps).
  2. **Vertical pass:** Convolves `d_tmp` along `y` into `d_dst` (`2r + 1` taps).
- **Complexity:** Reduces per-pixel work from `O(r^2)` to `O(2r)`.

## CPU Reference & Verification

- [src/blur_cpu.cpp](../src/blur_cpu.cpp) implements `box_blur_cpu`, direct 2D `gaussian_blur_2d_cpu`, and two-pass `gaussian_blur_separable_cpu`.
- [tests/test_blur_cpu.cpp](../tests/test_blur_cpu.cpp) runs 8 standalone checks covering kernel normalization/symmetry, radius-0 identity, constant-image preservation, impulse response, corner clamping, direct-vs-separable equivalence (`tol = 1e-4f`), channel independence, and binary PPM (P6) round-trip I/O.
- `blur_cuda` times each GPU kernel with `cudaEvent_t`, compares every output pixel against the CPU reference (`tol = 1e-3f`), prints speedup and `maxErr`/`mismatches`, and exits non-zero on any mismatch.
